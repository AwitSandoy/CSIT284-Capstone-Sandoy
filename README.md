* **Project Owner:** Awit Sandoy

## Project Description:
Mandela is a Flutter-based Class Schedule / Timetable Viewer web-application designed to help students efficiently manage their academic week. The application features a comprehensive weekly timetable view, a dedicated "today's classes" home screen, and built-in reminder notifications to keep students on track throughout their semester. Built with Material 3 defaults for clean and consistent UI performance.
